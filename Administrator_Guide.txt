OCC INVENTORY MANAGER
ADMINISTRATOR GUIDE

Version: 1.3.1

PURPOSE

This guide covers data storage, backups, upgrades, installation management, recovery, building, and troubleshooting for OCC Inventory Manager.

SYSTEM REQUIREMENTS

End-user computer:
- Windows 10 or Windows 11
- Approximately 250 MB of available disk space
- Permission to install software

Development computer:
- Windows 10 or Windows 11
- Python 3.11 or newer
- Inno Setup 6
- Internet access when required Python packages are not already installed

APPLICATION DATA

OCC Inventory Manager stores its SQLite database in the current Windows user's Local AppData folder.

The database is not stored in the application installation directory. Normal upgrades and reinstalls therefore do not overwrite inventory data.

Each Windows user account has its own Local AppData location. Inventory entered under one Windows account may not be available under another account unless the database is copied or restored for that user.

BACKUPS

Use the built-in database backup function regularly.

Recommended times to create a backup:
- Before installing an application update
- Before importing a large spreadsheet
- Before making major category changes
- Before moving the application to another computer
- Before replacing or servicing the computer
- At regular intervals based on inventory activity

Store at least one backup outside the computer running the application.

Suitable locations include:
- External drive
- Network storage
- Approved cloud storage
- Another secured computer

UPGRADING

1. Create a database backup.
2. Close OCC Inventory Manager.
3. Run the new installer.
4. Use the existing installation folder unless a different location is required.
5. Launch the application and verify that the inventory is present.

The installer remembers the previous installation folder when possible.

UNINSTALLING

The application can be removed through:
- Windows Settings, Apps, Installed apps
- Start Menu, OCC Inventory Manager, Uninstall OCC Inventory Manager
- The uninstaller located in the application installation folder

Uninstalling removes:
- Application files
- Start Menu shortcuts
- Desktop shortcut, if created
- Windows uninstall registration

Uninstalling does not automatically delete the inventory database stored in Local AppData.

MOVING TO ANOTHER COMPUTER

1. Create a database backup on the original computer.
2. Install OCC Inventory Manager on the new computer.
3. Close the application on the new computer.
4. Restore or copy the database backup to the correct application data location.
5. Launch the application.
6. Verify item quantities, categories, and reports.

Keep the original backup until the new installation has been verified.

IMPORT MANAGEMENT

Before importing:
- Create a database backup.
- Confirm that the file is CSV or XLSX.
- Confirm that the file contains an item-name column.
- Review category and subcategory names for consistency.

Duplicate rows are merged by adding quantities. Review imported totals after each import.

LOW-STOCK LOGIC

An item is considered low stock when:

quantity on hand is less than or equal to minimum needed

This means an item at exactly its minimum quantity is included in the low-stock report.

BUILDING THE APPLICATION AND INSTALLER

1. Confirm Python 3.11 or newer is installed.
2. Confirm Inno Setup 6 is installed.
3. Run build.bat.
4. Choose the installer output folder.
5. Select Build Application and Installer.
6. Review the status line and build activity.
7. Confirm that both files were created:
   - OCC Inventory Manager.exe
   - OCC_Inventory_Manager_Setup.exe

The builder uses the installed Python interpreter directly. It does not create a separate virtual environment.

The application executable is created in the project folder. The installer is saved in the selected output folder.

BUILD TROUBLESHOOTING

The build button appears to do nothing:
- Use version 1.3.1 or later.
- Check the status line and Build activity area.
- Review build_error.log in the project folder.
- Confirm the output folder is writable.
- Confirm required project files are present.

The builder window does not open:
- Confirm Python is installed.
- Confirm Python is available from the Windows command line.
- Run build.bat again.
- Check whether Windows security software blocked the script.

Inno Setup is not found:
- Install Inno Setup 6.
- Confirm ISCC.exe exists in the Inno Setup installation folder.
- Run build.bat again.

The installer reports that the executable is missing:
- Confirm OCC Inventory Manager.exe exists in the same folder as OCC_Inventory_Manager.iss.
- Run the graphical build again before compiling the installer.

The build fails while installing Python packages:
- Confirm the computer has internet access.
- Confirm Python includes pip.
- Review build_error.log.
- Run the build again after correcting the reported error.

APPLICATION TROUBLESHOOTING

The application does not start:
- Restart Windows.
- Reinstall the latest application version.
- Check whether antivirus software quarantined the executable.
- Record any displayed error message.

Inventory is missing:
- Confirm the same Windows user account is being used.
- Check whether the database was restored to the correct Local AppData location.
- Do not create new inventory until the correct database or backup has been located.

Import creates no items:
- Confirm the correct worksheet is being imported.
- Remove title rows above the column headers.
- Confirm an item-name column is present.
- Review the file for merged cells or unsupported formatting.
- Save the file as a new XLSX or CSV file and try again.

REPORTING A PROBLEM

Include:
- Application version
- Windows version
- Action being performed
- Complete error message
- Contents of build_error.log when the issue is build-related
- Whether the issue occurs every time
- Whether a recent import, update, or database restore was performed
