OCC INVENTORY MANAGER
RELEASE NOTES

Version: 1.3.1
Release Date: July 2026

OVERVIEW

Version 1.3.1 corrects the graphical builder so that selecting an output folder and starting the build provides immediate feedback and reliably launches the build process.

FIXED IN VERSION 1.3.1

- Corrected an issue where pressing Build Application and Installer could appear to do nothing.
- Removed creation of the private .venv build environment.
- The builder now uses the installed Python interpreter directly.
- Added immediate build status messages.
- Added validation for required project files.
- Added validation that the selected installer output folder is writable.
- Added visible handling for graphical interface callback errors.
- Added visible handling for build worker errors.
- Added build_error.log for complete troubleshooting details.
- Improved handling when the builder is launched through pythonw.exe.
- Updated the README and build documentation.
- Updated the application and installer version to 1.3.1.

BUILD PROCESS

The graphical builder now:

1. Checks required project files.
2. Uses the installed Python environment.
3. Installs or updates required Python packages.
4. Builds OCC Inventory Manager.exe in the project folder.
5. Locates the Inno Setup 6 compiler.
6. Compiles OCC_Inventory_Manager_Setup.exe.
7. Saves the installer in the selected output folder.
8. Displays the completed file locations.

BUILD REQUIREMENTS

The development computer must have:

- Windows 10 or Windows 11
- Python 3.11 or newer
- Inno Setup 6
- Internet access when Python packages need to be installed or updated

KNOWN LIMITATIONS

- Barcode scanning is not implemented.
- Item photographs are not implemented.
- Automatic application updates are not implemented.
- Multi-user and network database access are not implemented.
- Cloud synchronization is not implemented.
- User accounts and permissions are not implemented.
- The application is intended for local inventory management on one Windows computer.

UPGRADE NOTES

Version 1.3.1 can be installed over an earlier version. Inventory data is stored separately from the application files and should remain available after an upgrade.

Create a database backup before installing a new version.
